# SkyLink Voyages — Site

Site statique (un seul fichier HTML/JS/CSS) pour SkyLink Voyages. Il appelle le
backend [`skylink-backend`](https://github.com/foutatanke-lgtm/skylink-backend)
(hébergé sur Render) pour la recherche de vols et la création de réservations
réelles via Duffel.

Hébergé sur GitHub Pages — aucun serveur nécessaire, c'est un site 100% statique.
